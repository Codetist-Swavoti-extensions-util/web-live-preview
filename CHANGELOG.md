# Changelog

## Unreleased

### Added
- Minimal browser-style URL bar for the preview panel with a clean inline layout.
- Back and forward navigation controls for preview history.
- Inline reload action for refreshing the preview without extra chrome.
- Agent-connected status text in the URL bar when the preview is controlled by the Codetist AI agent.
- Compact, low-noise styling with a cleaner dark theme and no bulky card or status panels.

### Changed
- Removed the oversized branding, empty-state cards, sandbox chrome text, and extra action icons from the webview UI.
- Simplified the toolbar to focus on address entry and navigation controls.
- Kept the input as the main UI element while preserving a lightweight active-state feel.

### Notes
- The extension source remains unchanged from the original preview logic; the UX update is focused on the webview panel presentation and navigation flow.
